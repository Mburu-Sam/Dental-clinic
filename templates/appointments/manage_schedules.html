How It Works
Step 1 — Set Schedule

Click Add Schedule above or go to Doctor Admin. Set which days and times each doctor is available each week.

Step 2 — Generate Slots

Use the Generate Slots form above to automatically create bookable appointment slots for the next 2 or 4 weeks based on the doctor's schedule.

Step 3 — Patients Book

Patients see only the generated slots when they visit the booking page. Each slot can be booked by exactly one patient.
